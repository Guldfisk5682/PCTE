# 研究结论与下一步建议

## R4 的增益稳定，继续保留为主候选

seeds 41/42/43 的 R4−B 分别为 +1.7519、+1.6483、+1.9570 pp，配对均值
**+1.7857 ±0.1571 pp**。R4 最终 Macro 为 **74.6224 ±0.0457%**；R2 为
**74.4653 ±0.0341%**，相对 B 为 **+1.6286 ±0.1263 pp**。两者的追加 seed
已经完成，本轮重新审核和复用，不覆盖旧结果。

## 互补纠错存在，但一致性错误仍是主要限制

R4 Teacher 在三 seed 上平均纠正原 SPL 的 4.022% 样本，同时损坏原来正确的
2.059% 样本，净增伪标签准确率约 1.963 pp。Clipart 分别为 4.745%、2.851%。
这些是教师预测指标，不能与 Student 最终准确率混用。

250/500/750 步准入的即时 Teacher 收益为 +0.636、+0.324、+0.080 pp。
准入前后 Source 和 Student 不变，因此可直接观察教师加入对伪标签的作用。
第一次引入容易域的教师最有益；后来加入的教师未必在所有目标域上有正贡献。
例如 Product→Clipart 中，最终 Art Teacher 的 leave-one-out 边际贡献为
−0.122 pp，而 Real World Teacher 为 +0.092 pp。该分析不重训 Student。

必须区分实际 Prompt 投票与“原始 Base+Source SPL + Target Prompt”的投票。
Clipart 上，Source Prompt 和另外两个 Target Prompt 的实际一致率为 55.255%，
一致样本 Precision 为 73.454%，有 14.682% 的全部样本出现三 Prompt 一致错误。
将原始 Base+Source SPL 作为投票单位时，相应一致错误率为 21.232%。
相似度融合有时还会纠正所有首选类别都错误的预测，因此首选类别一致不等同于融合结果。

Clipart 的 Computer、Sink、Marker、Mop 等类别有明显相关错误。
下一阶段优先分析错误相关性、类别相似度 margin 和教师成熟度；不把一致率直接当成可靠度。

## 大 β 是强距离加权负收益的重要来源

固定完全相同的 R4 教师、Bank、准入时间和学生预算后，seed 42 的 Macro 为：

| β | Macro | 相对 R4 |
|---|---:|---:|
| 0 | 74.6224% | −0.0247 pp |
| 0.1 | 74.6557% | +0.0086 pp |
| 1 | 74.6884% | +0.0413 pp |
| 10 | 74.3588% | −0.2882 pp |

β=0 的 Mask 差异很小。β=10 时，多有效域的样本×类别位置有 28.068% 接近
One-hot，权重熵降至 0.336；β=1 时近 One-hot 为零，熵为 1.022，Macro
回升 0.330 pp。Art→Clipart 的 β=10 Source 权重为 82.214%，近 One-hot
比例 45.615%，体现部分任务对 Source 的强偏好。

扫描同时改变集中程度和教师偏好，**不能唯一证明 One-hot 本身是原因**。
在离线真实类别位置，正确教师投票权重甚至随 β 增大而增加，但其他类别的权重
也改变，整体分类决策仍会退化。类质心几何质量、单教师准确率和融合后的伪标签质量
需要分别分析。原 R5 的教师反馈也会改变后续 Bank，不能与固定 R4 扫描等同。

β=1 四个 Source 都略有收益，但总体仅 +0.041 pp，尚不支持为此增加 Bank。
保留 R4 Uniform；本轮没有继续扩展温度网格或加入其他算法。

## 渐进准入主要解决在线教师成熟度问题

同一 Student 预算下，从第 1 步固定使用全部初始、未训练 Target Teachers，
Macro 为 **72.5806%**，比 R4 低 **2.0664 pp**，四个 Source 均下降。
而完全相同的成熟 R4 Teachers 从第 1 步开放，Macro 为 **74.6533%**，
比渐进开放仅高 **0.0063 pp**，两个 Source 升、两个降。

这支持“先获得可用教师质量”的解释，尚未证明渐进时机有独立优势。
成熟教师提前开放是**使用未来快照的离线双阶段时机对照**：与渐进参考对照有相同
学生预算和教师质量，但共同教师准备额外需要每分支 1,000 次更新。它不能作为
与在线 R4 端到端预算相等的新方法。所有新方法目前只有 seed 42，不能据此宣称普遍等价。

继续使用 R4 的在线准入流程。若进一步研究准入必要性，应围绕成熟度与开放时机
分开控制，并补充时机对照的多 seed；不能让提前开放的教师更新策略也同时变化。

## 实施边界与证据

新增 28 个正式 run，50 项测试通过。每个新 run 都是 Source 和每个 Target 各
1,000 次更新，batch=30；Source 最终参数与 Bank 均逐项等于原 R4。
FUniform 所有 Prompt 逐项复现 R4，四个 β 的 Target Bank 逐项相同。
原 A/B/C 与 R0–R6 运行代码和结果保留；没有新损失、过滤、阈值调节或特征变换。
目标真标签只进入独立评估和离线分析，最终 Checkpoint 由固定预算决定。

新扫描均未达到“≥0.5 pp 且至少三个 Source 正收益”的预注册追加 seed 条件，
因此没有扩大实验矩阵。β 和时机结果属于单 seed 机制探索。

结合已有 [Luna 文献备忘录](../../docs/spl_reliability_literature.md)，本轮更值得保留的是
伪标签可靠度与几何度量失配的诊断方向；那些改变特征或损失的论文方法并未直接搬入本实现。
